Test build of Bobix 0.2.0. This is a pre-release; the newest stable version is still v0.1.3.

**This is the first build you can get from inside the app.** rc.8 was installed by hand; if you turned on **Get test builds** (Settings → App), Bobix now offers this version, asks first, then downloads, checks the signature and installs it. Copies older than rc.8 still need a hand install.

## What's new

**Start asks which branch new work starts from**
- The first Start in a repository asks "Start new work from which branch?" with the branches the remote has right now. Nothing is preselected.
- The answer is remembered for that repository. Start shows "From: develop" (click Change), and Settings → Work → Starting branch lets you edit it or empty it to be asked again.
- The worktree is cut from the remote's copy of that branch, and the merge / pull request targets it. Before, a Full start used the remote's default branch, which can be old code.
- Offline, a branch that no longer exists, or no remote: Start stops and says why.

**Open a session from wherever it shows**
- **Open session** on the Overview rows and the Today usage rows, on ↵ in ⌘K search, on the pet's card, and in the tray (menu bar) for up to five sessions waiting for you.
- A session that has ended can be reopened: in Claude desktop through its link, in a terminal with a toast that copies `claude --resume <id>`.
- When it can't open, it says why (no window, no Node.js, ended).

**A Full start interviews you before the plan**
- Claude restates the ticket and waits for your yes, then asks only what the ticket and the code can't answer, in rounds. Each question says where it comes from and offers "Out of scope for this ticket".
- The plan ends with a table: each requirement and answer → the step that covers it. The work log has new sections (Ticket, Questions, Later, Mapping) and Work shows them.
- While Claude asks, the pet shows waiting with the question and Bobix tells you once. You answer in Claude's own window; Bobix never answers for you.
- Quick start is unchanged.

## Known gaps

- Builds are not code-signed: macOS and Windows warn on first launch.
- A click on the real tray menu item was not checked by the automated run (it calls the same handler). Do it by hand.
- The interview was not run for real: it is tested for its rules text and parsing, not with a live ticket in Claude Desktop.
- The remembered branch is stored by the repository's path without its host, so two hosts with the same path share one answer.
- A repository whose remote has very many branches (GitLab) was not tried; the list asks the remote for all of them.
- Checked by eye on macOS only. Windows and Linux are covered by the CI smoke run, not by hand.
- **Room needs a tailnet where laptops can reach each other.** Company tailnets that only allow user → server don't work yet.
- Picture pets (a pet drawn from your own picture) are hidden in this build.
