Test build of Bobix 0.2.0. This is a pre-release; the newest stable version is still v0.1.3.

**This is the first build that updates itself.** Copies before it (rc.7 and older, 0.1.x) cannot update in the app, so install this one by hand, once. **Get test builds is off by default**: to get the next test build (rc.9) in the app, turn it on in Settings → App. Updates ask first and never install by themselves.

## What's new

**Update Bobix from inside the app**
- Bobix checks for a new version, asks you first, then downloads, checks the signature and installs it.
- Settings → **Get test builds** also offers versions ending in `-rc.N`. Off: only released versions. Turning it off never installs an older version.

**Help where you need it**
- A **"?"** next to each group and trickier setting says what it does.
- After an update, the tour shows just what is new, as one bubble. A new install doesn't get it. Setup → "Show the tour again" shows the whole tour.

**Work: Full start follows its session**
- A **Full** start in Claude runs in the ticket's own worktree, and the ticket follows that session. A started session is named by its first prompt, wherever Claude opens it.
- The ticket work log follows Bobix's language; MR/PR text and commits stay English.
- Start only in Work (Full / Quick); Sessions shows sessions only. You can change the folder in Start.

**Usage**
- Overview measures the effect of each change on your own sessions.

**Docs**
- The docs now say plainly what Bobix does with your data and what leaves your computer.

## What's fixed
- **No layout shift** on a tab switch, or as data arrives in the panel.
- **A closed tour** no longer switches back to Skills; the habits label box is no longer centred wrongly.
- **Pets:** the hover card names the file or command and holds still while tools run; a card closes when the cursor leaves the window on Linux (XWayland); a family's name starts under the parent, not in the middle of the family.
- **Linux (Wayland):** the panel comes forward at the first start.
- **Stuck flows, process limits, state size, big orgs and start safety** from the review before this build.

## Known gaps

- Builds are not code-signed: macOS and Windows warn on first launch.
- The in-app update has been checked up to the signed update list, not by updating a real copy: that needs rc.9.
- Checked by eye on macOS only. Windows and Linux are covered by the CI smoke run, not by hand.
- **Room needs a tailnet where laptops can reach each other.** Company tailnets that only allow user → server don't work yet.
- The ticket flow was not run inside the Claude desktop app by the automated checks.
- Picture pets (a pet drawn from your own picture) are hidden in this build.
