Test build of Bobix 0.2.0, a fix for rc.5. This is a pre-release; the newest stable version is still v0.1.3.

## What's fixed

- **Room and Skills → From your habits work in the installed app.** In rc.5 both failed with "Command … not allowed by ACL": the two commands were never granted to the panel's pages. Everything else in rc.5 is unchanged. The smoke run now calls both through the real app path, and a test fails if a command is added to the app without being granted.

## What to test

Install over rc.5 (macOS first), then:

- [ ] **Room.** Open Room: it loads with no error. Create a room, invite someone by Tailscale login, chat, make the draft and Decide. If you have a second machine on the same tailnet, join from it and check you see the same record.
- [ ] **Skills → From your habits.** Open Skills → From your habits: it loads with no error and shows its switches. With "Read my prompts" and the weekly scan on, Scan now still works.
- [ ] **Nothing else moved.** Open the other screens (Overview, Sessions, Work, Skills, Settings) and approve one permission from the pet.

## Known gaps

Carried over from rc.5:

- Builds are not code-signed: macOS and Windows warn on first launch.
- Checked by eye on macOS only. Windows and Linux are covered by the CI smoke run, not by hand; usage reading on those systems assumes Claude writes transcripts where it does on macOS.
- The room was tested on one Mac only, not between two machines.
- macOS asks once to allow incoming connections when you host a room.
- The ticket flow was not run inside the Claude desktop app.
- The ticket flow works with GitLab only.
- The skills audit does not edit plugin settings, and Bobix does not yet suggest a model at Start on a ticket or in a pet tip. The first audit after start reads 30 days of transcripts and can take several seconds.
- The hourly usage chart from the design is left out; Overview shows the live sessions' token split instead.
- Picture pets (a pet drawn from your own picture) are hidden in this build.
